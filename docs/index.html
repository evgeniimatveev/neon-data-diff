git diff for your dbt data.

Tests say your data is valid. neon-data-diff tells you what changed: on every pull request it branches your Neon database, runs dbt on the base and PR code, diffs the results in SQL and comments on the PR.

Install

    
One step in your workflow.

    
Add a Neon API key as a secret and the project ID as a variable. Your dbt profile reads its connection from environment variables, so base and head can use different schemas.

    

      

        

# .github/workflows/data-diff.yml
on:
  pull_request:
    paths: ["dbt/**"]
permissions:
  contents: read
  pull-requests: write
jobs:
  data-diff:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: evgeniimatveev/neon-data-diff@v0
        with:
          neon-api-key: ${{ secrets.NEON_API_KEY }}
          neon-project-id: ${{ vars.NEON_PROJECT_ID }}

      

      

        

# dbt/profiles.yml: connection from env vars
uber:
  target: default
  outputs:
    default:
      type: postgres
      host: "{{ env_var('DBT_HOST') }}"
      user: "{{ env_var('DBT_USER') }}"
      password: "{{ env_var('DBT_PASSWORD') }}"
      dbname: "{{ env_var('DBT_DBNAME') }}"
      schema: "{{ env_var('DBT_SCHEMA') }}"
      sslmode: require
